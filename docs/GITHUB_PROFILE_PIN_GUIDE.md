## Should This Repo Be Pinned?

Decision: `recommend pin`

Pin ClientDeliveryKitAgent if a GitHub profile slot is available and the
profile should emphasize AI automation consulting, client delivery, and
business workflow diagnosis.

Do not replace AgentHubControlCenter. AgentHubControlCenter remains the main
hub / AgentOps Command Center.

## Recommended Pinned Order

1. AgentHubControlCenter
2. ClientDeliveryKitAgent
3. BusinessOpsAgent
4. SocialPainFinderAgent
5. QuantLabAgent
6. NewsSignalAgent or CareerPilotAgent

If all six GitHub profile pin slots are already used, choose manually which
existing project to replace. Do not automate this decision.

## Manual Pin Steps

1. Open the GitHub profile page.
2. Choose "Customize your pins".
3. Search for `ClientDeliveryKitAgent`.
4. Select the repository.
5. Keep `AgentHubControlCenter` selected as the first-priority hub project.
6. Save the pinned repositories.

## Why It Does Not Replace AgentHubControlCenter

AgentHubControlCenter explains the complete portfolio architecture, manifest
registry, local action metadata, workflow simulations, useful signals, approval
gates, and public-safe AgentOps system. ClientDeliveryKitAgent is the applied
client-facing spoke that proves the delivery workflow.

The best portfolio story is hub plus spoke, not spoke replacing hub.
